# ``ISO_639``

@Metadata {
    @DisplayName("ISO 639")
    @TitleHeading("Swift Standards")
}

Type-safe representations and a checked-in registry for ISO 639 language codes.

Use ``ISO_639/Alpha2`` and ``ISO_639/Alpha3`` when a particular code width is
required, or ``ISO_639/LanguageCode`` when accepting either representation.

## Registry provenance

The Swift sources under `Generated` are the canonical registry snapshot. Changes
to that snapshot are reviewed against the Library of Congress ISO 639-2 registry;
the package does not carry a parallel JSON corpus or repository-local generator.
